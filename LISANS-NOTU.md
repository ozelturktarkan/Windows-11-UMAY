# Lisans kapsamı

Windows ve NTLite kendi sahiplerinin lisanslarına tabidir. Bu depo Windows lisansı veya aktivasyon hakkı sağlamaz. Windows ISO ve Microsoft ikilileri GitHub kaynak paketine dahil değildir. Özelleştirme dosyalarının paylaşılması Windows bileşenlerini kamu malı yapmaz; tüm içerik için toplu Public Domain/CC0 iddiası yoktur.
